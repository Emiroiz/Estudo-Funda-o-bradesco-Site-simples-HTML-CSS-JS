# Estudo Fundação Bradesco - Site Simples HTML, CSS e JavaScript

## 📖 Sobre o Projeto

Este repositório foi criado para armazenar os estudos e exercícios desenvolvidos durante os cursos da Fundação Bradesco, com foco em desenvolvimento web utilizando HTML, CSS e JavaScript.

O objetivo é praticar os conceitos fundamentais da criação de páginas web, incluindo estruturação de conteúdo, estilização e interatividade.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## 📂 Estrutura do Projeto

```text
/
├── index.html
├── css/
├── js/
└── assets/
```

*A estrutura pode variar conforme a evolução do projeto.*

## 🎯 Objetivos de Aprendizagem

* Criar páginas web utilizando HTML.
* Aplicar estilos com CSS.
* Desenvolver interatividade com JavaScript.
* Organizar arquivos de um projeto web.
* Praticar boas práticas de desenvolvimento.

## ▶️ Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/Emiroiz/Estudo-Funda-o-bradesco-Site-simples-HTML-CSS-JS.git
```

2. Abra a pasta do projeto.

3. Execute o arquivo `index.html` em qualquer navegador moderno.
